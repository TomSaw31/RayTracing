* # Ray Tracer in C++

A CPU ray tracer built from scratch in C++23 following Peter Shirley's tutorial series. This implementation modernizes the classic project layout by utilizing modern **C++20 Modules (`.cppm`)** for clean structural separation and automated documentation deployment.
